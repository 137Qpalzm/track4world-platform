## 二、模型架构总览

### 2.1 完整推理流水线

```
输入: 单目 RGB 视频 (B, T, 3, H, W)
  │
  ├─[1] 动态分辨率控制 ──→ 对齐至 14×14 patch 网格 + 64 整除
  │
  ├─[2] 骨干网络 (三选一)
  │     ├─ DINOv2-ViT-L (base模式, 304M参数)
  │     ├─ Pi3X (pi3模式, 稀疏深度+位姿)
  │     └─ DA3-GIANT (depthanythingv3模式, 1.1B参数)
  │     输出: 3D点图(T,H,W,3) + 掩码 + 世界坐标点 + 相机位姿(T,4,4)
  │           + 流特征图(T,128,H/8,W/8)  [仅flow分支]
  │
  ├─[3] 上下文编码 (ConvNeXt)
  │     输入: 原始图像(T,3,H,W)
  │     输出: 上下文特征(T,128,H/8,W/8)
  │
  ├─[4] 全局特征聚合 (Global_Aggregator, 基于VGGT)
  │     ├─ 帧级别注意力 (Temporal Attention)
  │     └─ 全局级别注意力 (Spatial Attention)
  │     输出: 聚合特征(T,128,H/8,W/8)
  │
  ├─[5] 滑动窗口迭代优化 (RAFT-style)
  │     对每个窗口(S=16帧, 步长=8):
  │     │
  │     │  ┌─ 全对相关性体积 (5层金字塔)
  │     │  │   CorrBlock: fmap1 × fmap2 → (B*S, 405, H/8, W/8)
  │     │  │
  │     │  ├─ 迭代更新 (4次):
  │     │  │   ├─ 相关性查找 → 运动编码 → 2D流更新
  │     │  │   ├─ 可见性置信度更新
  │     │  │   └─ [3D模式] 3D流更新 (几何约束)
  │     │  │
  │     │  └─ 学习式 8× 上采样 (Convex Upsampling)
  │     │
  │     输出: 2D光流(T,2,H,W) + 可见性(T,2,H,W) + [3D流(T,3,H,W)]
  │
  └─[6] 几何对齐 & 输出
        ├─ 2D光流 → 像素轨迹追踪
        ├─ 3D光流 + 深度 → 世界坐标密集追踪
        └─ 点云 (PLY) + 轨迹 (NPY) + 可视化 (MP4)
```

### 2.2 三种推理模式的调用路径

| 模式 | 入口函数 | 模型调用链 | 特点 |
|------|----------|-----------|------|
| **2d** | `forward_video()` | → `model.forward_sliding()` → `forward_window_unified()` | 仅2D光流，不需深度 |
| **3d_ff** | `forward_video3d_ff()` | → `model.infer()` → `forward_sliding()` → `forward_window_unified()` | 全序列3D追踪 |
| **3d_efep** | `forward_video3d_pair()` | → `model.infer_pair()` → `forward_sliding()` → `forward_window_unified()` | 帧对处理，适合长序列 |

## 三、核心模块详解

### 3.1 Track4World 主模型 (model.py)

**初始化参数**:
```python
Track4World(
    encoder='dinov2_vitl14',      # 骨干网络选择
    intermediate_layers=4,         # 特征金字塔层数
    dim_proj=512,                  # 投影维度
    dim_upsample=[256, 128, 64],  # Head上采样通道
    dim=128,                       # 流特征维度
    hdim=128,                      # 隐藏维度
    seqlen=16,                     # 滑动窗口长度
    corr_levels=5,                 # 相关性金字塔层数
    corr_radius=4,                 # 搜索半径
    use_3d=True,                   # 启用3D追踪
    use_model='base'               # 骨干模式 (base/pi3/depthanythingv3)
)
```

**关键方法**:

#### `forward_point()` — 几何与特征提取
```
输入: image (B*T, 3, H, W)
  │
  ├─ [base] DINOv2 中间层特征 → Head解码 → 3D点图 + 掩码
  ├─ [pi3]  Pi3X.inference() → 稀疏深度/位姿 → 反投影
  └─ [da3]  DA3.inference_v2() → 深度/内外参 → process_geometry()
  │
  输出 (for_flow=False):
    points:       (B, T, H, W, 3)     # 相机坐标系3D点
    world_points: (B, T, H, W, 3)     # 世界坐标系3D点
    mask:         (B, T, H, W)         # 有效性掩码
    camera_poses: (B, T, 4, 4)        # C2W变换矩阵

  输出 (for_flow=True): 额外返回
    fmaps:          (B*T, 128, H/8, W/8)  # 流特征
    ctxfeat:        (B*T, 128, H/8, W/8)  # 上下文特征
    fmaps3d_detail: (B*T, 64, H/8, W/8)  # 3D细节特征
    pm:             (B*T, 3, H/8, W/8)    # 低分辨率点图
```

#### `forward_window_unified()` — RAFT 迭代优化核心
```
每次迭代 (默认4次):
  1. 坐标计算: coords2 = coords1 + flow2ds8
  2. 相关性查找:
     fea_corr = CorrBlock(fmap1, fmap2)(coords2)  → (B*S, 405, H/8, W/8)
     cxt_corr = CorrBlock(cxt1, cxt2)(coords2)
  3. 运动编码:
     motion = positional_encoding(flow, bands=10)  → (B*S, 42, H/8, W/8)
  4. 2D流更新:
     flowfeat → RelUpdateBlock → flow_2d_head → Δflow2d
     flow2ds8 += Δflow2d
  5. 可见性更新:
     flowfeat → flow_visconf_head → Δvisconf
  6. [3D模式] 3D流更新:
     pm_corr + motion3d → RelUpdate3D → Δflow3d
     flow3ds8 += Δflow3d
  7. 上采样:
     weights = flow_upsample_weight(flowfeat)  → (B*S, 576, H/8, W/8)
     flow_full = convex_upsample_8x(flow2ds8, weights)  → (B*S, 2, H, W)
```

### 3.2 CorrBlock — 相关性体积 (blocks.py)

全对相关性计算 + 多尺度金字塔查找：

```
初始化:
  fmap1: (B, C, H, W)  ×  fmap2: (B, C, H, W)
  → 内积相关性: (B, H, W, 1, H, W)
  → 5层金字塔: [1×, 0.5×, 0.25×, 0.125×, 0.0625×]

查找:
  给定 coords (B, 2, H, W):
  → 在每层金字塔中以 radius=4 采样局部区域
  → 拼接5层: (B, 5 × 9², H, W) = (B, 405, H, W)
```

### 3.3 全局特征聚合 (global_aggregator.py)

基于 VGGT 的交替注意力机制：
- **帧级注意力**: 同一时间步内的空间注意力
- **全局注意力**: 跨时间步的时序注意力
- 使用 2D RoPE (旋转位置编码) 保留空间信息
- 深度 = 8层 (2D流) / 4层 (3D流)

### 3.4 上采样机制 (Convex Upsampling)

```python
def upsample_data(flow, mask, dim1=2):
    # flow: (B, dim1, H/8, W/8) — 低分辨率预测
    # mask: (B, 64*9, H/8, W/8) — 学习的权重

    # 对每个低分辨率像素, 预测8×8子像素的9邻域凸组合权重
    mask = mask.reshape(B, 1, 9, 8, 8, H, W)
    mask = torch.softmax(mask, dim=2)

    # 用3×3邻域加权求和 → 8× 上采样
    up_flow = Σ(mask[i,j] × flow_neighbor[i,j])
    return up_flow  # (B, dim1, H, W)
```

## 六、关键创新点分析

### 6.1 前馈式 3D 追踪
- 不同于传统逐帧迭代方法, Track4World 在**单次前向推理**中完成全序列追踪
- 通过滑动窗口 (S=16, stride=8) 处理任意长度视频

### 6.2 世界坐标系表示
- 通过 `process_geometry()` 将相机坐标系点云变换到统一世界坐标系
- 使用 C2W (Camera-to-World) 矩阵: `P_world = R @ P_cam + t`

### 6.3 几何-光流对齐
- 2D 光流和 3D 几何流并行估计
- `RelUpdate3D` 使用采样的几何特征引导 3D 流更新
- 几何一致性约束: 通过 `grid_sample` 在光流位移处采样3D点

### 6.4 多尺度相关性 + 迭代优化
- 5层相关性金字塔覆盖从精细到粗糙的匹配尺度
- 4次迭代逐步精细化: 每次使用上一次的流预测作为初始化
